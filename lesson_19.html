a. Spiral Review Warm-up (00:00-00:10) 🔄

Review of expanding brackets and solving linear equations.

Tinjauan ekspansi tanda kurung dan penyelesaian persamaan linear.

Let's recall how to expand $(x+a)(x+b) = x^2 + (a+b)x + ab$. Example: $(x+2)(x-2) = x^2 - 4$.

Mari kita ingat cara ekspansi $(x+a)(x+b) = x^2 + (a+b)x + ab$. Contoh: $(x+2)(x-2) = x^2 - 4$.

Also, solving linear equations like $3x + 5 = 0 \implies x = -\frac{5}{3}$.

Juga, menyelesaikan persamaan linear seperti $3x + 5 = 0 \implies x = -\frac{5}{3}$.

b. Introduction & Real-World Connection (00:10-00:15) 🌍

Parabolas are everywhere!

Parabola ada di mana-mana!

Imagine throwing a ball; its path is a parabola ($y = ax^2 + bx + c$). A laser beam is a straight line ($y = mx + c$). If the laser hits the ball, the point of contact is the intersection.

Bayangkan melempar bola; jalurnya adalah parabola ($y = ax^2 + bx + c$). Sinar laser adalah garis lurus ($y = mx + c$). Jika laser mengenai bola, titik kontaknya adalah perpotongan.

c. Review of Prior Knowledge (00:15-00:20) 📚

Key concepts you must know:

Konsep kunci yang harus Anda ketahui:

  • $y = mx + c$ is a straight line where $m$ is gradient, $c$ is y-intercept.$y = mx + c$ adalah garis lurus di mana $m$ gradien, $c$ perpotongan y.
  • $y = ax^2 + bx + c$ is a parabola. If $a>0$, it opens upwards.$y = ax^2 + bx + c$ adalah parabola. Jika $a>0$, terbuka ke atas.
  • To find x-intercepts, set $y=0$. To find y-intercept, set $x=0$.Untuk mencari perpotongan x, set $y=0$. Untuk perpotongan y, set $x=0$.

d. Problem Introduction (00:20-00:25) 📝

Cambridge Problem:

Soal Cambridge:

The curve $C$ has equation $y = x^2 - 4$ and the straight line $l$ has equation $y + 3x = 0$.

Kurva $C$ memiliki persamaan $y = x^2 - 4$ dan garis lurus $l$ memiliki persamaan $y + 3x = 0$.

  • (a) Sketch $C$ and $l$ on the same axes.Sketsa $C$ dan $l$ pada sumbu yang sama.
  • (b) Write down coordinates where $C$ meets axes.Tuliskan koordinat di mana $C$ memotong sumbu.
  • (c) Find coordinates where $l$ intersects $C$.Cari koordinat di mana $l$ memotong $C$.

Step-by-step solution:

Pembahasan langkah demi langkah:

(c) Intersection: Equate equations: $y = -3x$ and $y = x^2 - 4$. So, $x^2 - 4 = -3x \implies x^2 + 3x - 4 = 0$.

(c) Perpotongan: Samakan persamaan: $y = -3x$ dan $y = x^2 - 4$. Maka, $x^2 - 4 = -3x \implies x^2 + 3x - 4 = 0$.

Factor: $(x - 1)(x + 4) = 0 \implies x = 1$ or $x = -4$.

Faktorkan: $(x - 1)(x + 4) = 0 \implies x = 1$ atau $x = -4$.

Find $y$: If $x=1, y=-3(1)=-3$. Point is $(1, -3)$. If $x=-4, y=-3(-4)=12$. Point is $(-4, 12)$.

Cari $y$: Jika $x=1, y=-3(1)=-3$. Titiknya $(1, -3)$. Jika $x=-4, y=-3(-4)=12$. Titiknya $(-4, 12)$.
